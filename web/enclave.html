Haptix Enclave. A passkey wallet for trading agents.

The first Haptix: an ERC-4337 smart account that gives an AI agent a scoped, time-boxed session key, and hands anything larger or unrecognised back to the owner's passkeys. It won Track A of the Binance Agent OS Mini Hackathon.

This page describes an earlier build that runs on BNB Chain testnet. Haptix is independent and not affiliated with Binance. The current project is Haptix for Agent ID, live on mainnet.

01What it did

Three tiers, decided on-chain.

Every call the agent makes is classified inside the smart account before it runs. The policy reads the inner calldata (transfers, approvals, permits), not just the value attached to the call.

Tier 1

The agent acts alone

SESSION KEY

Small, recognised calls go through with the agent's own session key. No prompt for the owner.

  • Time-boxed and revocable
  • Per-transaction and per-window limits
  • Allowed protocols, functions and tokens only

Tier 2

The owner's passkeys decide

PASSKEY QUORUM

Larger calls, and anything the policy can't positively identify as low-risk, need the owner's WebAuthn passkeys.

  • P-256 signatures checked on-chain
  • Approvals and permits always escalate
  • Allowlist, not blocklist

Tier 3

It fails closed

REVERTED

Above the hard limit, or while the account is frozen, the call reverts before any funds move.

  • Emergency freeze switch
  • Recipient allowlist for one-signature transfers
  • No relayer can override it

02How it's built

From a market signal to a signed UserOp.

1 · Signal

Market data

The agent reads live prices and spreads.

2 · Decision

Agent core

It picks a trade or a rebalance and its size.

3 · Session key

Scoped UserOp

Signed with the agent's key, inside its session limits.

4 · Smart account

PasskeyAccount

ERC-4337 v0.7. SpendPolicy picks the tier; passkeys sign when it escalates.

5 · Chain

BNB Chain

Runs through the EntryPoint, or reverts.

Passkey signatures use the P-256 precompile (RIP-7212). Accounts are cheap ERC-1167 clones from a factory.
